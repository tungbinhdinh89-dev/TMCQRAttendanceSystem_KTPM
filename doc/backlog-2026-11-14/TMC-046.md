## TMC-046 · Prepare the GitHub Project field schema

**Type:** CHORE · **Feature:** foundation · **Priority:** P0 · **Area:** devops

**Parent:** [TMC-101](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/107)
**Dependencies:** [TMC-045](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/49)
**Assignee / estimate / target date:** Chưa phân công hoặc cam kết; người phụ trách cập nhật sau refinement.

### Problem / Outcome
Khảo sát owner/repo/Project hiện có và quyền; tạo hoặc tái sử dụng Project khi được giao thực thi; cấu hình Status/Priority/Rank/Estimate/Start/Target/Iteration và Feature mapping.

### Scope / Implementation checklist
- [ ] Khảo sát owner/repo/Project hiện có và quyền
- [ ] tạo hoặc tái sử dụng Project khi được giao thực thi
- [ ] cấu hình Status/Priority/Rank/Estimate/Start/Target/Iteration và Feature mapping.

### Acceptance criteria
- [ ] AC1: Owner/audience/Project URL/ID lấy từ phản hồi thật, không tự thay quyền hoặc tạo Project trùng.
- [ ] AC2: Fields/options/types đúng schema §8, một nguồn Status/Priority; dates/estimate map ticket đúng.

### Verification plan
- [ ] Walkthrough field của issue thật hoặc dry configuration review; ghi mức xác minh.
- [ ] Không tự giả custom people-picker/organization issue type hoặc mirror tự động.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `doc/backlog.md`; kiểm tra đường dẫn thực tế khi nhận việc.

### Definition of Done
- [ ] Mọi AC trong scope có evidence thật; build/typecheck/tests phù hợp phần thay đổi đạt; UI có visual check nếu áp dụng.
- [ ] Thay đổi đúng bounded context; contracts không phụ thuộc framework/ORM; thay schema có migration/constraint plan, không synchronize.
- [ ] PR được người dùng review/nghiệm thu; không tự merge/approve hoặc đánh dấu Done.
- [ ] Cập nhật tài liệu và giới hạn; simulator không chứng minh tích hợp thiết bị/HRS thật.
