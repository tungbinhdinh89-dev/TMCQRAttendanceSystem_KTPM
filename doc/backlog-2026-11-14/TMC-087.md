## TMC-087 · Isolate session use cases from persistence and HTTP adapters

**Type:** REFACTOR · **Feature:** authorization · **Priority:** P1 · **Area:** security

**Parent:** [TMC-089](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/95)
**Dependencies:** [TMC-007](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/7)
**Assignee / estimate / target date:** Chưa phân công hoặc cam kết; người phụ trách cập nhật sau refinement.

### Problem / Outcome
AuthService hiện ở application nhưng import Nest exceptions, TypeORM và ORM entities; tách ports/mapping/wiring tối thiểu theo architecture đã chọn, giữ auth behavior.

### Scope / Implementation checklist
- [ ] AuthService hiện ở application nhưng import Nest exceptions, TypeORM và ORM entities
- [ ] tách ports/mapping/wiring tối thiểu theo architecture đã chọn, giữ auth behavior.

### Acceptance criteria
- [ ] AC1: Pure application/domain không phụ thuộc Nest/TypeORM/ORM; wiring ở bootstrap, HTTP errors map ở presentation.
- [ ] AC2: Session/hash/RBAC behavior và API contract giữ nguyên, không thêm feature auth ngoài scope.

### Verification plan
- [ ] Auth/bootstrap tests trước/sau và positive/negative session scenarios không đổi.
- [ ] Boundary tests 085 và DI bootstrap xác nhận adapter replacement, không đổi registry/schema vô cớ.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `api/src/modules/iam/application/auth.service.ts`, `api/src/modules/iam/presentation/auth.controller.ts`, `api/src/bootstrap/modules/iam.module.ts`, `api/test/auth.service.test.mjs`; kiểm tra đường dẫn thực tế khi nhận việc.

### Definition of Done
- [ ] Mọi AC trong scope có evidence thật; build/typecheck/tests phù hợp phần thay đổi đạt; UI có visual check nếu áp dụng.
