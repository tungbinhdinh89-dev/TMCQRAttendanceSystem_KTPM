### Scope / Implementation checklist
- [ ] Nối Employees UI tới API scoped profiles/grants/revoke

### Acceptance criteria
- [ ] AC1: Bộ lọc/query/pagination chỉ lấy scope cho phép, ghi server và reload phản ánh dữ liệu thật.
- [ ] AC2: HR revoke/deactivate có lý do/audit; role không được phép không có action và server vẫn từ chối.
- [ ] AC3: Form lưu qua API và reload đọc đúng dữ liệu; bỏ badge Dữ liệu mẫu trên màn dùng dữ liệu thật; không thông báo thành công khi API lỗi.

- [ ] Thử hai factory, validation/409/403/empty/network failure và reload sau ghi.
- [ ] Visual/responsive đối chiếu UI guidelines, không localStorage fallback báo thành công giả.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.
