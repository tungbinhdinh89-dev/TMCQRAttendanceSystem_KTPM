### Acceptance criteria
- [ ] AC1: Harness/config dữ liệu và timestamp/UI boundary tái lập, không dùng trung bình để chứng minh peak.
- [ ] AC2: Báo distribution/max/error/timeout/correctness tại tải và so ≤2s; môi trường/giới hạn có nguồn.

- [ ] Baseline và burst do owner chốt; fail khi thiếu UI measurement hoặc mất dữ liệu dù API nhanh.

- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.
