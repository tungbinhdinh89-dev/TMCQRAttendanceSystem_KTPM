### Problem / Outcome
Thêm UI chọn role và scope từ dữ liệu server cho phép; hiển thị hiệu lực/thu hồi và lỗi conflict, không hardcode quyền rộng.

### Scope / Implementation checklist
- [ ] Thêm UI chọn role và scope từ dữ liệu server cho phép
- [ ] hiển thị hiệu lực/thu hồi và lỗi conflict, không hardcode quyền rộng.

### Acceptance criteria
- [ ] AC1: Dropdown org hierarchy hợp lệ, assignment/revoke reload đúng, quyền sửa do server quyết định.
- [ ] AC2: Lỗi self-escalation/stale version có thông điệp an toàn; không âm thầm lưu local.

### Verification plan
- [ ] GLOBAL/FACTORY/TEAM và invalid combinations; actor không được cấp quyền tương ứng bị server chặn.
- [ ] Keyboard/responsive/error/empty states được kiểm tra.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `client/src/features/settings/Settings.tsx`, `contracts/src/auth.ts`; kiểm tra đường dẫn thực tế khi nhận việc.

### Definition of Done
- [ ] Mọi AC trong scope có evidence thật; build/typecheck/tests phù hợp phần thay đổi đạt; UI có visual check nếu áp dụng.
- [ ] Thay đổi đúng bounded context; contracts không phụ thuộc framework/ORM; thay schema có migration/constraint plan, không synchronize.
- [ ] PR được người dùng review/nghiệm thu; không tự merge/approve hoặc đánh dấu Done.
- [ ] Cập nhật tài liệu và giới hạn; simulator không chứng minh tích hợp thiết bị/HRS thật.
