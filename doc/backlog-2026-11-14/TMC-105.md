## TMC-105 · Connect shift and schedule screens to persisted APIs

**Type:** UI · **Feature:** extended-business · **Priority:** P2 · **Area:** frontend

**Parent:** [TMC-099](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/105)
**Dependencies:** [TMC-104](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/93), [TMC-057](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/61)
**Assignee / estimate / target date:** Chưa phân công hoặc cam kết; người phụ trách cập nhật sau refinement.

### Problem / Outcome
saveShift/assignShift hiện luôn từ chối; cần nối API ca/lịch sau khi contract được chốt.

### Scope / Implementation checklist
- [ ] Nối danh sách/form ca, gán ca theo hiệu lực và lịch sử vào API thật.
- [ ] Dùng factory/department/team IDs từ server; hỗ trợ loading/empty/403/409/lỗi mạng và thao tác bàn phím.

### Acceptance criteria
- [ ] AC1: Tạo/sửa/gán lịch và reload vẫn đúng DB; lỗi API không hiển thị thành công.
- [ ] AC2: UI ca đêm và hiệu lực nhất quán policy; chỉ mở nút theo capability server, API vẫn kiểm tra quyền.

### Verification plan
- [ ] E2E HR đúng scope CRUD và gán lịch; EMP chỉ xem lịch cá nhân nếu được cấp.
- [ ] Kiểm tra responsive, lỗi mạng và stale update 409.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `client/src/features/shifts`, `client/src/data/api.ts`, `client/src/features/employees`; kiểm tra đường dẫn thực tế khi nhận việc.

### Definition of Done
- [ ] Mọi AC trong scope có evidence thật; build/typecheck/tests phù hợp phần thay đổi đạt; UI có visual check nếu áp dụng.
- [ ] Thay đổi đúng bounded context; contracts không phụ thuộc framework/ORM; thay schema có migration/constraint plan, không synchronize.
- [ ] PR được người dùng review/nghiệm thu; không tự merge/approve hoặc đánh dấu Done.
- [ ] Cập nhật tài liệu và giới hạn; simulator không chứng minh tích hợp thiết bị/HRS thật.
