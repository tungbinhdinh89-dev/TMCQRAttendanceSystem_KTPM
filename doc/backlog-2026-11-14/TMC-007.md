## TMC-007 · Complete server session authorization and scope checks

**Type:** ENHANCEMENT · **Feature:** authorization · **Priority:** P0 · **Area:** security

**Parent:** [TMC-089](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/95)
**Dependencies:** [TMC-005](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/5), [TMC-006](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/6)
**Assignee / estimate / target date:** Chưa phân công hoặc cam kết; người phụ trách cập nhật sau refinement.

### Problem / Outcome
Login/me/logout cookie session đã có. Bổ sung permission guard/policy và scope theo từng operation; giữ session authentication, đề không yêu cầu JWT.

### Scope / Implementation checklist
- [ ] Tách xác thực session và kiểm tra permission/scope thành guard/policy tái sử dụng; mặc định từ chối.
- [ ] Áp dụng ở API nghiệp vụ ngay khi tạo; kiểm tra object thuộc factory/department/team/self từ dữ liệu server.
- [ ] Chốt semantics nhiều role assignment; không ghép scope của role này với permission của role khác.

### Acceptance criteria
- [ ] AC1: Sửa localStorage/role/filter không nâng quyền gọi API.
- [ ] AC2: ADM không tự có quyền HR correction; SUP không truy cập nhân viên ngoài tổ.
- [ ] AC3: Session hết hạn/thu hồi trả 401; thiếu quyền trả 403 theo contract.
- [ ] AC4: Request hợp lệ nhưng thiếu permission hoặc ngoài scope bị 403 khi gọi API trực tiếp.
- [ ] AC5: Nhiều assignment được xử lý theo policy đã chốt, không mất scope hợp lệ hoặc tự mở rộng quyền.

### Verification plan
- [ ] Thử login sai, hết hạn, logout rồi dùng lại token.
- [ ] API tests IDOR hai nhân viên/hai nhà máy; station gọi API portal và ngược lại.
- [ ] Xác minh cookie/CSRF và log không chứa session secret/password.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `api/src/modules/iam`, `api/src/platform/infrastructure/database/seeds`, `api/test/auth.service.test.mjs`; kiểm tra đường dẫn thực tế khi nhận việc.

### Definition of Done
- [ ] Mọi AC trong scope có evidence thật; build/typecheck/tests phù hợp phần thay đổi đạt; UI có visual check nếu áp dụng.
- [ ] Thay đổi đúng bounded context; contracts không phụ thuộc framework/ORM; thay schema có migration/constraint plan, không synchronize.
- [ ] PR được người dùng review/nghiệm thu; không tự merge/approve hoặc đánh dấu Done.
- [ ] Cập nhật tài liệu và giới hạn; simulator không chứng minh tích hợp thiết bị/HRS thật.
