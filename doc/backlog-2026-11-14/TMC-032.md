## TMC-032 · Verify the complete user journey and UI states

**Type:** TEST · **Feature:** verification · **Priority:** P0 · **Area:** frontend

**Parent:** [TMC-102](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/108)
**Dependencies:** [TMC-021](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/21), [TMC-023](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/23), [TMC-030](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/30), [TMC-031](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/31), [TMC-085](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/89)
**Assignee / estimate / target date:** Chưa phân công hoặc cam kết; người phụ trách cập nhật sau refinement.

### Problem / Outcome
Chạy E2E P0 từ portal→virtual kiosk→history→recovery. Webcam/dashboard chỉ kiểm tra bổ sung nếu P1 được chọn; không để P0 phụ thuộc chúng.

### Scope / Implementation checklist
- [ ] Tự động hóa login EMP, lấy QR, scan virtual, mock passage và kiểm tra history API/UI.
- [ ] Chạy denied/expired/replay/UNKNOWN và journal reload bằng backend fixtures.
- [ ] Đối chiếu mobile 360/tablet/desktop, keyboard, focus, chữ/icon trạng thái, light/dark với baseline.
- [ ] Ghi ảnh/video, URL/môi trường và Figma source nếu được cung cấp; chưa có Figma URL phải ghi giới hạn.

### Acceptance criteria
- [ ] AC1: E2E P0 pass không cần camera vật lý hoặc dashboard P1.
- [ ] AC2: Không có dữ liệu real/mock trộn mà không nhãn, không xuất hiện đã ghi công ở ACK-only.
- [ ] AC3: Browser refresh và session switch không làm rò cache.

### Verification plan
- [ ] Chạy E2E trên ít nhất browser demo được chọn.
- [ ] Manual negative camera nếu đã làm 027; dashboard count nếu đã làm 028.
- [ ] Kiểm tra console errors, assets và responsive baseline.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `client/src/features/kiosk/Kiosk.tsx`, `client/src/features/employee-mobile/Mobile.tsx`, `api/test`, `report`; kiểm tra đường dẫn thực tế khi nhận việc.

### Definition of Done
- [ ] Mọi AC trong scope có evidence thật; build/typecheck/tests phù hợp phần thay đổi đạt; UI có visual check nếu áp dụng.
- [ ] Thay đổi đúng bounded context; contracts không phụ thuộc framework/ORM; thay schema có migration/constraint plan, không synchronize.
- [ ] PR được người dùng review/nghiệm thu; không tự merge/approve hoặc đánh dấu Done.
- [ ] Cập nhật tài liệu và giới hạn; simulator không chứng minh tích hợp thiết bị/HRS thật.
