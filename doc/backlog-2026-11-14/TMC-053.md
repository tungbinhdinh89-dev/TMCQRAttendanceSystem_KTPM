## TMC-053 · Verify payload redaction and session data isolation

**Type:** TEST · **Feature:** verification · **Priority:** P0 · **Area:** backend

**Parent:** [TMC-031](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/31)
**Dependencies:** [TMC-030](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/30), [TMC-050](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/54), [TMC-021](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/21)
**Assignee / estimate / target date:** Chưa phân công hoặc cam kết; người phụ trách cập nhật sau refinement.

### Problem / Outcome
Kiểm tra JSON/log/cache/QR payload không lộ secrets hoặc dữ liệu ngoài scope; logout/đổi user không giữ dữ liệu identity trước.

### Scope / Implementation checklist
- [ ] Kiểm tra JSON/log/cache/QR payload không lộ secrets hoặc dữ liệu ngoài scope
- [ ] logout/đổi user không giữ dữ liệu identity trước.

### Acceptance criteria
- [ ] AC1: QR/token/session/hash/secret không đi vào log hoặc response không được phép.
- [ ] AC2: Bootstrap/history/report projection và client cache theo identity, EXE chỉ aggregate.

### Verification plan
- [ ] Thu safe response/log mẫu của anonymous/EMP/EXE và so field allowlist.
- [ ] Logout rồi đăng nhập tài khoản khác, kiểm tra cache/URL/reload; lưu screenshot đã loại PII.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `api/src/modules/iam`, `api/src/modules/cfg/presentation/demo-bootstrap.controller.ts`, `client/src/app/context.tsx`, `client/src/data/api.ts`; kiểm tra đường dẫn thực tế khi nhận việc.

### Definition of Done
- [ ] Mọi AC trong scope có evidence thật; build/typecheck/tests phù hợp phần thay đổi đạt; UI có visual check nếu áp dụng.
- [ ] Thay đổi đúng bounded context; contracts không phụ thuộc framework/ORM; thay schema có migration/constraint plan, không synchronize.
- [ ] PR được người dùng review/nghiệm thu; không tự merge/approve hoặc đánh dấu Done.
- [ ] Cập nhật tài liệu và giới hạn; simulator không chứng minh tích hợp thiết bị/HRS thật.
