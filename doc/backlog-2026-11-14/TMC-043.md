## TMC-043 · Deliver the IAM administration interface

**Type:** UI · **Feature:** administration · **Priority:** P2 · **Area:** frontend

**Parent:** [TMC-098](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/104)
**Dependencies:** [TMC-007](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/7), [TMC-008](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/8), [TMC-060](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/64), [TMC-061](https://github.com/tungbinhdinh89/TMCQRAttendanceSystem_KTPM/issues/65)
**Assignee / estimate / target date:** Chưa phân công hoặc cam kết; người phụ trách cập nhật sau refinement.

### Problem / Outcome
P2: mở rộng IAM management screens. Auth/RBAC tối thiểu P0 dùng seed và APIs đã kiểm tra, không chờ full console.

### Scope / Implementation checklist
- [ ] Tạo user/role/scope assignment APIs có permission quản trị và audit.
- [ ] Tạo UI danh sách/form với scope shape SELF/GLOBAL/FACTORY/DEPARTMENT/TEAM.
- [ ] Thu hồi sessions khi disable/revoke theo policy; giữ lịch sử assignments.
- [ ] Chặn tự cấp đặc quyền không được phép, không tạo implicit HR correction quyền ADM.

### Acceptance criteria
- [ ] AC1: Role/scope persistence đúng unique/shape constraints.
- [ ] AC2: ADM quản trị được IAM theo quyền nhưng không tự sửa công HR.
- [ ] AC3: Mọi thay đổi có actor/reason/audit và cross-scope negative tests.

### Verification plan
- [ ] Scope NULL uniqueness, revoke và stale sessions.
- [ ] Self escalation/IDOR/invalid scope references.
- [ ] UI conflict/error/empty và permission guards.
- [ ] Chọn lệnh check từ manifest tại revision thực hiện. Không truyền --runInBand cho Node test runner. Integration chỉ dùng môi trường DB test đã chỉ định; không reset/seed DB hiện tại.

### Deliverables
- PR/diff, contracts/migration khi có thay đổi và evidence gắn revision; đánh giá từng AC, lỗi và giới hạn.
- Module/file định hướng: `client/src/features/settings/Settings.tsx`, `client/src/lib/rbac.ts`, `contracts/src/auth.ts`; kiểm tra đường dẫn thực tế khi nhận việc.
